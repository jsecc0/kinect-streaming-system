-----------------------
setup.sh                      - Main installation orchestrator

📁 scripts/ - Installation Modules
-----------------------------------
install_kinect_sdk.sh         - Azure Kinect SDK installation
install_python_deps.sh        - Python dependencies installation
install_mediamtx.sh           - MediaMTX streaming server installation
setup_permissions.sh          - USB device permissions setup
create_services.sh            - Systemd service creation

💻 APPLICATION CODE
-------------------
📁 src/
  kinect_streamer.py          - Main streaming application (FastAPI)

📁 services/                  - Systemd service files (auto-generated)

📁 web/                       - Web viewer (to be populated)


INSTALLATION ORDER
==================

1. Edit config.env
2. Run sudo ./setup.sh
3. Run sudo ./test_installation.sh
4. Start services
5. Test streams


CREATED FILES AFTER INSTALLATION
=================================

System Files:
  /etc/systemd/system/kinect-streamer.service
  /etc/systemd/system/mediamtx.service
  /etc/mediamtx/mediamtx.yml
  /etc/udev/rules.d/99-k4a.rules

Installation:
  /opt/kinect-streaming/            - Main installation directory
  /opt/kinect-streaming/src/        - Application code
  /opt/kinect-streaming/config/     - Configuration
  /opt/kinect-streaming/logs/       - Application logs
  /opt/kinect-streaming/web/        - Web interface

Logs:
  /var/log/kinect-streaming/        - Service logs
  /var/log/mediamtx/                - MediaMTX logs

Binaries:
  /usr/local/bin/mediamtx           - MediaMTX executable


FILE SIZES
==========
Total package size: ~50KB (before installation)
After installation: ~500MB (includes SDK and dependencies)


QUICK COMMANDS
==============

View all files:
  ls -laR /home/claude/kinect-streaming-system

Check installation:
  sudo ./test_installation.sh

Start streaming:
  sudo systemctl start kinect-streamer

View logs:
  sudo journalctl -u kinect-streamer -f
